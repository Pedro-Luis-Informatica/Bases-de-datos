# 📋 Práctica Aleatoria: Procedimientos Almacenados (SQL)

| Bloque | Ejercicio A | Ejercicio B |
| :--- | :--- | :--- |
| **01 - 02** | **Ej 1:** Crear un procedimiento que reciba un código de producto y devuelva el total de dinero generado por ese producto. | **Ej 2:** Crear un procedimiento que reciba una ciudad y devuelva cuántos clientes viven en esa ciudad. |
| **03 - 04** | **Ej 3:** Crear un procedimiento que reciba un DNI de cliente y devuelva cuántas facturas ha realizado ese cliente. | **Ej 4:** Crear un procedimiento que reciba un sabor y devuelva el precio promedio de los productos de ese sabor. |
| **05 - 06** | **Ej 5:** Crear un procedimiento que reciba un barrio y devuelva cuántos vendedores trabajan en ese barrio. | **Ej 6:** Crear un procedimiento que reciba un rango de precios (mínimo y máximo) y devuelva cuántos productos están en ese rango. |
| **07 - 08** | **Ej 7:** Crear un procedimiento que reciba un estado y devuelva el total de ventas realizadas en ese estado. | **Ej 8:** Crear un procedimiento que reciba una matrícula de vendedor y devuelva cuántos clientes diferentes ha atendido. |
| **09 - 10** | **Ej 9:** Crear un procedimiento que reciba un mes (1-12) y un año, y devuelva cuántas facturas se realizaron en ese mes y año. | **Ej 10:** Crear un procedimiento que reciba un envase (Botella, Lata, etc.) y devuelva el producto más caro de ese envase. |
| **11 - 12** | **Ej 11:** Crear un procedimiento que reciba un código de producto y devuelva el precio promedio al que se ha vendido. | **Ej 12:** Crear un procedimiento que reciba un DNI de cliente y devuelva el promedio de gasto por factura (ticket promedio). |
| **13 - 14** | **Ej 13:** Crear un procedimiento que reciba una fecha y devuelva cuántas facturas se hicieron en esa fecha. | **Ej 14:** Crear un procedimiento que reciba un sabor (Naranja, Limón, etc.) y devuelva cuántos productos tienen ese sabor. |
| **15 - 16** | **Ej 15:** Crear un procedimiento que reciba una matrícula de vendedor y devuelva el total de ventas que ha realizado. | **Ej 16:** Crear un procedimiento que reciba un código de producto y devuelva el precio máximo y mínimo al que se ha vendido. |
| **17 - 18** | **Ej 17:** Crear un procedimiento que reciba un barrio y devuelva cuántos clientes viven en ese barrio. | **Ej 18:** Crear un procedimiento que reciba un año y devuelva el total de ventas realizadas en ese año. |
| **19 - 20** | **Ej 19:** Crear un procedimiento que reciba un DNI de cliente y devuelva el total de la factura más alta que ha realizado. | **Ej 20:** Crear un procedimiento que reciba un código de producto y devuelva la cantidad total de unidades vendidas de ese producto. |
| **21 - 22** | **Ej 21:** Crear un procedimiento que reciba un estado (SP, RJ, etc.) y devuelva cuántos clientes hay en ese estado. | **Ej 22:** Crear un procedimiento que reciba una matrícula de vendedor y devuelva el promedio de ventas por factura. |
| **23 - 24** | **Ej 23:** Crear un procedimiento que reciba un DNI de cliente y devuelva cuántos productos diferentes ha comprado (distinct). | **Ej 24:** Crear un procedimiento que reciba un envase (Botella, Lata, etc.) y devuelva cuántos productos usan ese envase. |
